Projects

Three projects I built while learning web technologies. Each one runs live on this site.

Academic Planner

A task manager for students, built with JavaScript. You can add tasks with an optional due date, tick them off when they're done, delete them, and clear all completed tasks at once. Tasks are saved in the browser so they remain after a refresh. Building it taught me DOM manipulation, event handling and working with arrays of objects.

HTML, CSS, JavaScript

Live demo Source code

Contact Form Validator

A contact form that checks every field before it is accepted. It rejects empty fields, badly formatted email addresses, and phone numbers containing anything other than digits, and shows a clear error message under each field. I built it to practise form validation with regular expressions and event handling.

HTML, CSS, JavaScript, regular expressions

Live demo Source code

Student Portfolio Website

This website: a five-page, mobile-friendly portfolio with a consistent colour scheme, a responsive navigation menu, Flexbox and CSS Grid layouts, and hover and fade-in animations. It uses semantic HTML, an external stylesheet and shared JavaScript, and is hosted on GitHub Pages.

HTML, CSS, Flexbox, Grid, GitHub Pages
